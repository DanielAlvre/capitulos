\section{Arquitectura del Sistema}

\begin{itemize}
    \item El programa de obtención de muestreo residirá en un entorno on-premise (en el dispositivo del usuario). Se encargará de capturar los datos, realizar un preprocesamiento básico y enviarlos a la nube.
    \item El sistema de almacenamiento de fotogramas, el entrenamiento del modelo y el despliegue del algoritmo de clasificación se llevarán a cabo en la nube, lo que permitirá escalabilidad y automatización de procesos.
    \item La decisión de desplegar el sistema de traducción en la nube o en un entorno on-premise se basará en un análisis de varios factores, como costo y latencia.
\end{itemize}


\section{Desarrollo de un Sistema de Reconocimiento de Señas}

El sistema de reconocimiento de señas que se desarrollará tiene como objetivo principal la captura y procesamiento de la información de la posición de las falanges de la mano y el antebrazo, utilizando una cámara web. Para el seguimiento de las manos, se empleará \textbf{MediaPipe Holistic} o una API similar de \textbf{hand tracking}, que cumpla con los criterios de precisión, velocidad, facilidad de integración y soporte para el reconocimiento de la \textbf{Lengua de Señas Mexicana (LSM)}.

Este trabajo se enfoca en la configuración manual de la forma y posición de las manos y antebrazos durante la ejecución de las señas. Es relevante considerar que, al usar una cámara, se presentan ciertas limitaciones en cuanto al campo de visión. Aunque este enfoque ofrece mayor flexibilidad en comparación con algunos sensores, factores como el entorno y la distancia a la cámara pueden afectar la calidad de la captura. Por lo tanto, el sistema estará centrado en la parte superior del cuerpo del usuario, desde los antebrazos hacia arriba, incluyendo las manos, que son las áreas clave para la expresión en LSM.

A continuación, se describe el flujo de trabajo del sistema, ilustrado en los diagramas de secuencia. Estos diagramas proporcionan una visión detallada de cómo se lleva a cabo el proceso de captura, procesamiento y predicción de las señas.

El flujo de trabajo del sistema se desglosa de la siguiente manera:

\begin{itemize}
    \item \textbf{Iniciar Grabación/Toma de Fotos}: El usuario inicia el proceso, activando la captura de video o fotos.
    \item \textbf{Captura y Procesamiento de Datos}: El sistema divide el video en frames y almacena los datos localmente antes de subirlos a la nube.
    \item \textbf{Almacenamiento y Notificación}: Los frames se almacenan en un bucket de S3, y se envían notificaciones a través de \textbf{EventBridge}.
    \item \textbf{Invocación de Microservicios}: Un microservicio se activa para procesar los frames, utilizando \textbf{MediaPipe} para extraer las características relevantes de las manos y antebrazos.
    \item \textbf{Entrenamiento y Predicción}: Los modelos de aprendizaje automático se entrenan con los datos procesados. Cuando el usuario inicia la traducción, el sistema captura nuevos frames, predice las palabras en base a un modelo local y genera el audio correspondiente a la seña.
\end{itemize}

El sistema no solo tiene como objetivo el reconocimiento preciso de las señas, sino también la facilitación de la comunicación mediante la generación de audio en tiempo real, que se reproducirá para el usuario. Además, el enfoque en la parte superior del cuerpo garantiza una captura adecuada de la expresión manual, fundamental para el reconocimiento de la LSM.

En el diagrama de secuencia a continuación ilustran el flujo completo del sistema. En el primer diagrama (Figura \ref{fig:diagrama_composicion}), se describe el proceso general desde la captura de los datos hasta su procesamiento.

\begin{itemize}
    \item \textbf{Proceso de Muestreo}
    \begin{itemize}
        \item El proceso de reconocimiento comienza cuando el usuario realiza un gesto específico de inicio, como alzar la mano.
        \item A partir de ese momento, se capturan fotogramas (frames) de la seña.
        \item Los fotogramas capturados se almacenan en la nube (por ejemplo, Amazon S3).
        \item Los datos almacenados serán procesados posteriormente.
    \end{itemize}

    \item \textbf{Proceso de Extracción de Datos y Entrenamiento}
    \begin{itemize}
        \item La API de MediaPipe Holistic (u otra similar) se encargará de procesar los fotogramas y extraer la posición de los puntos de referencia relevantes en las manos y antebrazos.
        \item Se recopilan suficientes muestras de entrenamiento.
        \item Un microservicio en Python con TensorFlow o Keras entrenará un modelo de aprendizaje profundo.
        \item El modelo entrenado se desplegará en la nube para garantizar escalabilidad y manejo eficiente de las solicitudes de entrenamiento.
    \end{itemize}

    \item \textbf{Reconocimiento y Traducción de Señas}
    \begin{itemize}
        \item El sistema realiza el reconocimiento de las señas utilizando el modelo entrenado.
        \item Las señas reconocidas se traducen a texto o audio.
        \item El sistema proporciona una respuesta en tiempo real, facilitando la comunicación.
    \end{itemize}
\end{itemize}


El algoritmo entrenado clasificará la seña emitida, comparándola con las señas previamente clasificadas y entradas. Para ello, utilizará la información de la posición de los puntos de referencia proporcionada por la API de hand tracking y realizará un mapeo a la configuración manual de la seña, como entrada al modelo. Una vez que se logre el reconocimiento de una seña dentro de la LSM, el sistema proporcionará la traducción al español, seguida de un mensaje de voz generado mediante una API de Text-To-Speech.

\section{Interfaz de usuario de la aplicación}

La aplicación móvil se ha diseñado con una interfaz intuitiva y fácil de usar, priorizando la usabilidad para proporcionar una experiencia de usuario fluida y accesible. Esto es especialmente importante para asegurar que el sistema sea accesible para personas con discapacidad auditiva. A continuación, se describen las principales pantallas de la aplicación, diferenciando entre los roles de usuario (administrador y general) cuando sea necesario:

\subsection{Splash Screen}

\pantalla{1}{Splash Screen de la aplicación.}

Esta es la primera pantalla que se muestra al iniciar la aplicación. Su función principal es mostrar el ícono de la aplicación mientras se cargan los componentes necesarios.  Es visible tanto para usuarios administradores como generales.

\subsection{Login}

\pantalla{2}{Pantalla de inicio de sesión.}

Esta pantalla permite a todos los usuarios iniciar sesión en la aplicación. Se requiere una dirección de correo electrónico y una contraseña para la autenticación, la cual se gestiona a través de Firebase.

\subsubsection{Funcionalidad}

\begin{itemize}
    \item \textbf{Inicio de sesión con correo electrónico y contraseña:} Disponible para todos los usuarios.
    \item \textbf{Inicio de sesión con Google:} Disponible solo para usuarios con rol general.
    \item \textbf{Registro de nuevo usuario:} Permite a los usuarios que no están registrados crear una cuenta utilizando su correo electrónico y contraseña, o a través de su cuenta de Google.
\end{itemize}

\subsection{Pantalla de registro (Usuario general)}

\pantalla{3}{Pantalla de registro de usuarios.}

Esta es la pantalla por la cual los usuarios nuevos, pueden generar un registro.
\subsubsection{Funcionalidad}
\begin{itemize}
    \item \textbf{Registro de nuevo usuario:} Permite a los usuarios que no están registrados crear una cuenta utilizando su correo electrónico y contraseña, o a través de su cuenta de Google.
\end{itemize}

\subsection{Pantalla principal (Usuario general)}

    \item \textbf{Acceder a las opciones generales:} Todas las pantallas a partir de acá, cuentan con esa funcionalidad de permitir al usuario acceder al menú de acciones de acuerdo a su rol.

\subsection{Pantalla descriptiva de la seña  (Usuario general)}

\pantalla{5}{Pantalla del diccionario LSM.}

Esta es la pantalla donde los usuarios generales pueden ver los recursos multimedia que describen a la seña.

\subsubsection{Funcionalidad}
\begin{itemize}
    \item \textbf{Acceder a la descripción de la seña:} Muestra breve reseña de lo que significa la seña, así como imágenes y videos relacionados con la seña, que nos muestran...
\end{itemize}

\subsection{Pantalla de cámara}

\pantalla{9}{Pantalla de cámara.}

Esta es la pantalla principal donde los usuarios pueden grabar sus señas para el análisis y evaluación.

\subsubsection{Funcionalidad}
\begin{itemize}
    \item \textbf{Grabar señas:} Permite al usuario capturar las muestras de las señas emitidas para ser procesadas por el sistema.
    \item \textbf{Previsualización en tiempo real:} Muestra un recuadro de la cámara en tiempo real para que el usuario pueda ajustar su posición antes de grabar.
\end{itemize}

\subsection{Pantalla menu}
\pantalla{6}{Menú principal para los usuarios}

Esta es la pantalla que permite a los usuarios generales navegar entre las diferentes secciones de la aplicación. Las opciones disponibles incluyen:

\subsubsection{Funcionalidad}
\begin{itemize}
    \item \textbf{Perfil:} Acceso a la información personal del usuario y opciones para modificarla.
    \item \textbf{Diccionario de Lengua de Señas Mexicana (DLM):} Acceso al conjunto de señas disponibles en la aplicación.
    \item \textbf{Destacados:} Visualización de las señas más populares o relevantes.
    \item \textbf{Salir:} Permite cerrar sesión o salir de la aplicación.
\end{itemize}

\subsection{Pantalla del perfil del usuario}

\pantalla{7}{Pantalla de perfil del usuario.}

Esta pantalla permite a los usuarios ver y modificar su información general registrada en la aplicación.

\subsubsection{Funcionalidad}
\begin{itemize}
    \item \textbf{Visualizar información personal:} Permite al usuario verificar sus datos, como nombre, correo electrónico y otra información relevante.
    \item \textbf{Modificar datos:} Ofrece opciones para actualizar o corregir los datos personales registrados.
\end{itemize}

\subsection{Pantalla de perfil: Sección de señas}

\pantalla{8}{Pantalla de la sección de señas del perfil.}

Esta pantalla, dentro del perfil del usuario, proporciona información específica sobre el progreso del usuario respecto al uso de la aplicación.

\subsubsection{Funcionalidad}
\begin{itemize}
    \item \textbf{Nivel actual:} Muestra el nivel del usuario en la aplicación, de acuerdo con las señas aprendidas.
    \item \textbf{Cantidad de señas emitidas:} Indica la cantidad total de señas realizadas o aprendidas por el usuario.
\end{itemize}

\subsection{Pantalla de destacados}

\pantalla{10}{Pantalla de destacados.}

En esta pantalla, los usuarios pueden visualizar los nombres de los usuarios destacados junto con sus respectivos puntos de clasificación.

\subsubsection{Funcionalidad}
\begin{itemize}
    \item \textbf{Clasificación por puntos:} Muestra a los usuarios mejor clasificados según el número de puntos obtenidos en la aplicación.
    \item \textbf{Orden jerárquico:} Presenta los usuarios en orden descendente de puntos, destacando al mejor clasificado.
\end{itemize}
\subsection{Pantalla de administración (Usuario administrador)}

\pantalla{11}{Pantalla de administración.}

Esta pantalla está diseñada para los usuarios con rol de administrador y les permite gestionar el contenido de la aplicación.

\subsubsection{Funcionalidad}
\begin{itemize}
    \item \textbf{Agregar señas:} Permite al administrador incorporar nuevas señas al diccionario de la aplicación.
    \item \textbf{Editar descripciones:} Facilita la modificación de descripciones asociadas a las señas existentes.
    \item \textbf{Gestión multimedia:} Da la opción de agregar imágenes o videos relacionados con las señas.
\end{itemize}

Esta pantalla es visible para cualquier usuario que desee realizar el reconocimiento de señas. Una vez completada la carga de los pesos (previamente entrenados en la red neuronal y descargados automáticamente desde la nube mediante un script Bash), la aplicación comienza a capturar las señas desde la cámara web. Posteriormente, en tiempo real, se procesan los puntos clave de las manos y el torso mediante Mediapipe, permitiendo identificar las señas emitidas por el usuario.
