\subsection{Diagrama de clases del sistema}

El diagrama de clases que se presenta a continuación proporciona una representación detallada de las principales entidades y sus relaciones dentro del sistema, \textbf{como se visualiza en la Figura \ref{fig:diagrama_clases}}. Este diagrama define las clases principales del sistema, como los usuarios, roles, actividades y las señas que el sistema maneja. A través de este diagrama, se puede observar la estructura del sistema y cómo las funciones específicas, como la autenticación, el reconocimiento de señas y la gestión de roles, están organizadas en el contexto del sistema de procesamiento de la Lengua de Señas Mexicana (LSM).

\subsection{Tecnologías Utilizadas}

A continuación, se detallan las principales tecnologías que serán utilizadas para el desarrollo del sistema:

\begin{itemize}
    \item \textbf{MediaPipe Holistic (o API similar)}: Captura y procesamiento de datos de la cámara, utilizada para detectar y rastrear las señas realizadas por el usuario.
    \item \textbf{TensorFlow}: Framework de aprendizaje profundo utilizado para entrenar y desplegar modelos de redes neuronales, como las Redes Neuronales Convolucionales (CNN) y las LSTM (Long Short-Term Memory).
    \item \textbf{Amazon S3}: Almacenamiento de fotogramas y datos en la nube, utilizado para almacenar imágenes, videos y otros archivos relacionados con las señas.
    \item \textbf{Python}: Lenguaje de programación principal para el desarrollo de la lógica del sistema, procesamiento de datos y entrenamiento de modelos.
    \item \textbf{API de Text-To-Speech}: Generación de mensajes de voz que ayudarán en la interacción del usuario con el sistema.
    \item \textbf{Microservicios, SQS, Lambda, EventBridge}: Componentes para la arquitectura en la nube (si se opta por esa opción), utilizados para la gestión de servicios distribuidos y la automatización de procesos en la nube.
    \item \textbf{Tecnologías web}: Sistema web (en conjunto con su framework), utilizado para la interfaz de usuario y la interacción con la plataforma.
    \item \textbf{Firebase}: Plataforma para el desarrollo de aplicaciones móviles y web, utilizada para la autenticación de usuarios y el almacenamiento en tiempo real de datos.
    \item \textbf{Amazon EC2}: Servicio de computación en la nube de Amazon Web Services (AWS), utilizado para desplegar y ejecutar instancias de servidor que soporten el procesamiento y la ejecución de tareas del sistema.
    \item \textbf{Amazon SQS}: Servicio de colas de mensajes de AWS, que se utilizará para gestionar y procesar los mensajes de manera asíncrona dentro de la arquitectura distribuida.
    \item \textbf{AWS Lambda}: Servicio de computación sin servidor de AWS, empleado para ejecutar código en respuesta a eventos, como la captura y procesamiento de datos.
    \item \textbf{AWS CloudFormation}: Servicio de AWS para automatizar el despliegue de recursos y la gestión de infraestructura como código, permitiendo la creación y gestión de recursos en la nube de manera automatizada.
    \item \textbf{AWS SAM (Serverless Application Model)}: Modelo de aplicación sin servidor de AWS, utilizado para desarrollar, probar y desplegar aplicaciones sin servidor en la infraestructura de AWS.
\end{itemize}
