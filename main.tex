% Resumen
\chapter*{Resumen}
\addcontentsline{toc}{chapter}{Resumen}
    Este proyecto desarrolla un sistema que reconoce señas de la Lengua de Señas Mexicana (LSM) para facilitar la comunicación entre personas con discapacidad auditiva y la comunidad oyente en México. El sistema se basa en la captura de la configuración manual de las señas mediante cámara y utiliza MediaPipe para el seguimiento de las manos. Se enfoca principalmente en el reconocimiento de señas con movimiento, particularmente en el ámbito médico. La traducción de un conjunto predefinido de señas al español se logra mediante modelos de aprendizaje profundo, utilizando TensorFlow/Keras. La integración de tecnología en la nube permite un procesamiento de datos escalable y una posible traducción en tiempo real. El objetivo final es cerrar la brecha de comunicación entre personas con discapacidad auditiva y oyentes, promoviendo una mayor inclusión y accesibilidad en México.
    \textbf{keywords:}
    Lengua de Señas Mexicana (LSM), Reconocimiento de Señas, Seguimiento de Manos (Hand Tracking), Algoritmos de Aprendizaje Automático, Redes Neuronales Convolucionales (CNN), Redes Neuronales LSTM, Automatización de Procesos, AWS (Amazon Web Services), Interfaz de Usuario, Análisis de Datos.

% Abstract
\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}
This project develops a system that recognizes signs from Mexican Sign Language (LSM) to facilitate communication between people with hearing disabilities and the hearing community in Mexico. The system is based on capturing the manual configuration of signs through a camera and uses MediaPipe for hand tracking. It focuses primarily on recognizing signs with movement, particularly those related to the medical field. The translation of a predefined set of signs into Spanish is achieved through deep learning models, using TensorFlow/Keras. The integration of cloud technology allows for scalable data processing and potential real-time translation. The ultimate goal is to bridge the communication gap between people with hearing disabilities and hearing people, promoting greater inclusion and accessibility in Mexico.
\textbf{Keywords:}
Mexican Sign Language (LSM), Sign Language Recognition, Hand Tracking, Machine Learning Algorithms, Convolutional Neural Networks (CNN), LSTM Neural Networks, Process Automation, AWS (Amazon Web Services), User Interface, Data Analysis.
